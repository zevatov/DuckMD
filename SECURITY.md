# SECURITY.md — модель угроз DuckMD

> Версия: 0.6.15 · Обновлён: 2026-09-15

## 1. Что делает DuckMD (контекст модели угроз)

DuckMD — это сверхбыстрый нативный Markdown-редактор и ридер для macOS. Вся обработка документов, парсинг синтаксического дерева (AST) и HTML-рендеринг выполняются **строго локально**.

**Сетевой активности в DuckMD нет**: приложение не открывает исходящих сетевых соединений, не подключает удалённые CDN, не содержит аналитических трекеров, телеметрии и фоновой синхронизации.

## 2. Границы доверия (trust boundaries)

| Граница | Что пересекает | Комментарий |
|---|---|---|
| Приложение ⇄ Локальная ФС | Чтение и запись `.md`, `.markdown`, `.txt` файлов | Только файлы, явно открытые пользователем через Open Panel или Drag & Drop |
| Приложение ⇄ WebKit (WKWebView) | Локальный HTML/CSS рендер превью | Генерация чистого HTML из AST; изоляция веб-контента, отсутствие доступа к внешним скриптам |
| Приложение ⇄ Диск | Локальный кэш последних файлов в `~/Library/Application Support/DuckMD/` | Список недавних путей (Recent Files) |
| Приложение ⇄ Сеть | — | **Отсутствует** (полная изоляция) |

## 3. WebKit и превью документов

- DuckMD использует встроенный движок `WKWebView` для мгновенного превью форматированного Markdown.
- Все стили и скрипты синхронизации скролла встроены непосредственно в бинарный бандл приложения и загружаются локально без обращения к сторонним серверам.
- Доступ к локальным системным файлам из контекста веб-страницы заблокирован.

## 4. Данные на диске и конфиденциальность

- DuckMD никогда не сохраняет и не передает содержимое ваших заметок на сторонние серверы.
- Автосохранение выполняется атомарно непосредственно в исходный файл документа на диске пользователя.

## 5. Подпись и дистрибуция

- Приложение собирается с включенным **Hardened Runtime** для защиты от инъекций кода.
- Дистрибуция осуществляется в виде подписанного DMG-образа.
