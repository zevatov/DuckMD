# DuckMD — UX / Экраны (UX)

> Все экраны, флоу, состояния, ASCII-макеты, поведение.
> Требования см. в `SPEC.md`, реализация моделей — в `ARCHITECTURE.md`, статус реализации — в `CHANGELOG.md`.

## 1. Вайб и визуальный язык

| Параметр | Значение |
|---|---|
| **Тон** | Спокойный, тёплый, «как Apple Notes», ничего лишнего |
| **Акцент** | Жёлтый утки `#FFC800` (`Color(red:1, green:0.78, blue:0)`) — H1, чекбоксы, выделение, активные элементы |
| **Типографика** | `-apple-system`, `SF Pro Text`, `SF Pro Display`, код — `SF Mono`, интерлиньяж 1.65 |
| **Отступы** | Колонка чтения 720pt по умолч., мягкие вертикальные отступы между блоками (12pt) |
| **Поверхности** | Liquid Glass на тулбаре/баннерах (нативный macOS 26), `.regularMaterial` на карточках хаба |
| **Скругления** | 10pt для код-блоков/карточек/таблиц, 12pt для крупных контейнеров |
| **Тема** | Тёмная/светлая следует за системой (переключается в настройках) |
| **Анимации** | Плавные `.easeInOut(0.18)` для переключения режимов, opacity transitions |

### 3.2. Поведение

- **Карточка недавнего файла** (`HubCardView`):
  - Иконка документа (или мини-утка).
  - Название (из H1 или имени файла) — marquee при наведении, поповер «(i)» со сведениями.
  - Мини-превью: первые ~3 строки отрендеренного текста, обрезанные.
  - Метаданные: «N сл», дата («сегодня 14:20» / «вчера» / «5 мая»).
  - **Одиночный клик** → открыть в документе (факт v0.6.15, Этап 4: [`onTapGesture`](../DuckMD/Views/HubCardView.swift:97), как у карточек действий хаба).
  - **Правый клик** → контекстное меню: «Открыть», «Показать в Finder», «Удалить из недавних» ([`contextMenu`](../DuckMD/Views/HubCardView.swift:102)). ⚠️ Известное ограничение (Этап 4): пункта «Открыть с помощью…» нет (SPEC R-HUB-6).
  - ⚠️ Если файл удалён с диска → серая карточка с плашкой «не найден» ([`HubCardView`](../DuckMD/Views/HubCardView.swift:31), фон [`gray.opacity(0.1)`](../DuckMD/Views/HubCardView.swift:84)) — **известное ограничение Этапа 4**: хаб фильтрует несуществующие файлы ([`filteredAndSortedFiles`](../DuckMD/App/RecentFilesStore.swift:285), [`load()`](../DuckMD/App/RecentFilesStore.swift:84)), поэтому серое состояние в живом UI недостижимо (SPEC R-HUB-7); кнопки «Убрать» в карточке нет — удаление из недавних только через контекстное меню.
- **Карточка «+ Новый документ»** (первая в сетке):
  - Клик → `NSSavePanel` → создаёт пустой `.md` → открывает в документе в режиме `.code`.
- **Карточка «Конвертировать в MD»**:
  - Клик → `NSOpenPanel` (фильтр: `.docx/.pdf/.html/.rtf/.txt`) → `ConverterView`.
- **Drag & Drop на окно хаба**:
  - `.md` → открыть/обновить в недавних.
  - Другой поддерживаемый → конвертация.
- **Поиск**: фильтрует карточки по названию И содержимому (по кешированному превью).
- **Сортировка** (dropdown): Дата открытия (по умолч.) / Дата изменения / Имя / Размер.
- ⚠️ **Подвал — известное ограничение (v0.6.15, Этап 4)**: в [`HubView`](../DuckMD/Views/HubView.swift:19) подвала с версией нет; версия показывается в About ([`AboutView`](../DuckMD/Views/AboutView.swift:14)) и в Настройках ([`SettingsView`](../DuckMD/Views/SettingsView.swift:221)) — читается из Bundle (единый источник — `MARKETING_VERSION` в `project.yml` → `CFBundleShortVersionString`); пункт «О DuckMD» — в меню приложения (SPEC R-BRAND-7). Макет ниже — целевое состояние (исторически фигурировали `v0.5.0 Beta` / `0.6.2` / `v0.6.6`).
- **⚙ Настройки**: открывает `SettingsView`.

### 4.3. Режим «Правка» (split)

```
┌──────────────────────────────────────────────────────────────────┐
│ [← Хаб]  Отчёт          [Просмотр|Правка|Код]                     │
├──────────────────────────────┬───────────────────────────────────┤
│  РЕДАКТОР КОДА (слева)        │  ЖИВОЙ РЕНДЕР (справа)            │
│                              │ ║                                 │
│  # Отчёт GPT-5               │ ║   Отчёт GPT-5  (жёлтый)         │
│                              │ ║                                 │
│  Обычный абзац с **жирный    │ ║   Обычный абзац с жирным        │
│  текст|                      │ ║   текст                         │
│                              │ ║                                 │
│  - Список                    │ ║   • Список                      │
│  - Второй|                   │ ║   • Второй                      │
│                              │ ║                                 │
│                              │ │                                 │
│         ▲                    │ │     ▲ разделитель               │
│         (каретка тут)        │ ║     (перетаскиваемый)           │
└──────────────────────────────┴───────────────────────────────────┘
```

- Левая часть — `CodeEditorView` с подсветкой + автоформатированием.
- Правая часть — превью в WKWebView ([`WebPreviewView`](../DuckMD/Views/WebPreviewView.swift)), живо следует за `document.text`.
- **Smart Centered Sync Scroll (v0.6.6)**: 
  - Прокрутка с обеих сторон синхронизируется по центральной горизонтальной линии экрана (`midY`).
  - При пролистывании разновысоких элементов (например, длинный блок кода или таблица) скорость прокрутки подстраивается динамически, чтобы фокус внимания оставался по центру.
  - Жёсткая доводка до $y = 0$ и $y = \text{maxScroll}$ устраняет отсечение первой и последней строк.
- GFM-чекбоксы `- [ ]`/`- [x]` **интерактивны в превью**: клик по `input` отправляет toggle в редактор (SPEC R-MD-4); в экспортном HTML — статичный span `☐`/`☑`.
- **Интерактивный WYSIWYG клик**: клик по блоку рендера наводит курсор и подсвечивает соответствующую строку в редакторе кода.
- **Разделитель** перетаскиваемый, `splitRatio` в диапазоне **0.2–0.8** (clamp при drag в [`SplitEditorView`](../DuckMD/Views/SplitEditorView.swift:234), фиксация при отпускании — [`SplitEditorView`](../DuckMD/Views/SplitEditorView.swift:238)). Факт v0.6.15 (Этап 4): значение — **сессия процесса** ([`AppState.splitRatio`](../DuckMD/App/AppState.swift:18), персист между запусками не заявлен — в отличие от сортировки хаба R-HUB-8).
- Печатаешь слева → справа обновляется мгновенно.

### 4.4. Режим «Код»

Полноэкранный `CodeEditorView` с подсветкой синтаксиса Markdown. Тот же редактор, что в split, но на всю ширину.

### 4.5. Баннер внешнего изменения (`ExtChangeBanner`)

Появляется сверху под тулбаром, когда внешний процесс изменил открытый файл:

```
┌──────────────────────────────────────────────────────────────────┐
│ ⚠ Файл изменён внешне. Обновление через 5с...   [Отменить]        │
└──────────────────────────────────────────────────────────────────┘
```

- Таймер обратного отсчёта (5с по умолч., настраивается).
- **[Отменить]** → восстановить предыдущую версию текста (из памяти). v0.6.15 hardening: отмена ДО авто-применения = «оставить мои» — текущий текст пишется на диск (с read-back), диск и память согласованы; при ошибке записи автосейв остаётся приостановленным.
- По истечении → авто-применение.
- Если есть **несохранённые локальные правки** → другой текст: «⚠ Файл изменён внешне, но у вас есть несохранённые правки. [Применить внешние] [Оставить мои]». v0.6.15 hardening: внешний текст, не применённый в редактор из-за фокуса, ставится в очередь и предлагается этим баннером (не теряется); side-by-side diff НЕ реализован — бинарный выбор.
- **v0.6.15 (дополнительные состояния, hardening потери данных):**
  - **Файл удалён другим приложением** → модальный диалог «Восстановить / Закрыть документ»; автосейв приостановлен; «Восстановить» пишет текущий текст обратно и перезапускает вотчер.
  - **Файл нечитаем** (невалидный UTF-8 / ошибка FS) при внешнем событии → диалог «Закрыть документ / Продолжить без записи»; автосейв приостановлен, запись только явным «Сохранить».
  - Невалидный UTF-8 при открытии → ошибка открытия, документ не создаётся, автосейв не стартует (оригинал не затирается).
  - Детали — в [`CHANGELOG.md`](../CHANGELOG.md) (v0.6.15, hardening файлового слоя).

### 4.6. Состояния документа

| Состояние | Поведение |
|---|---|
| **Пустой документ** (новый) | `EmptyStateView`: утка + «Начни печатать (режим Код) или вставь текст» |
| **Очень длинный документ** | Виртуализация/ленивый рендер не обязателен для MVP, но рендер должен держаться <300ms |

### 5.2. Поддерживаемые исходные форматы

| Формат | Источник | Заметка |
|---|---|---|
| `.txt` | тривиально | текст как есть + нормализация переносов |
| `.rtf` | `NSAttributedString(url:)` | маппинг атрибутов (bold/italic) → `**`/`*` |
| `.html` | `NSAttributedString` (AppKit HTML-парсер) | ссылки, списки, заголовки; ⚠️ внешние ресурсы файла могут запрашиваться — известное ограничение (v0.6.15, см. N-6 в `SPEC.md`) |
| `.docx` (и `.rtfd`) | `NSAttributedString` (AppKit, `.officeOpenXML`/`.rtfd`) | текст + маппинг bold/italic/ссылок → MD ([`ConverterService`](../DuckMD/Conversion/ConverterService.swift:80)) |
| `.pdf` | `PDFKit` (`PDFDocument`) | текст постранично; сканы → «нужен OCR» |

### 5.3. Флоу

```
выбор файла → автоопределение формата → [Конвертировать]
   → прогресс (для больших PDF/docx)
   → превью MD
   → [Сохранить как .md] (NSSavePanel) ИЛИ [Открыть в DuckMD] (с сохранением во времен.)
   → добавить в RecentFilesStore
```

### 6.2bis. Секция «Приватность» (v0.6.15, Этап 2)

На вкладке «Редактор», после настроек редактора, отдельная группа [`SettingsView`](../DuckMD/Views/SettingsView.swift):

- **«Загружать удалённые изображения»** — тумблер, по умолчанию **выключен**. Выключено: http/https-картинки в превью не загружаются (защита от трекинг-пикселей), вместо них плейсхолдер с alt-текстом; локальные изображения документа не затрагиваются. Включено: удалённые картинки рендерятся как обычно. Подсказка `.help()` объясняет оба состояния.

## 8. Доступность (Accessibility)

- Все иконочные кнопки имеют `accessibilityLabel` (русский).
- Сегментированный переключатель режимов — `accessibilityValue` с текущим режимом.
- Карточки хаба — `accessibilityElement(children: .combine)` с описанием «документ, название, X слов».
- Рендер Markdown — `textSelection(.enabled)`, VoiceOver читает текст.
- Поддержка Dynamic Type / системного размера шрифта.
- Контраст текста соответствует WCAG AA.

## 9. Адаптивность

| Размер окна | Поведение |
|---|---|
| Малый (<600pt) | Сетка хаба → 2 колонки; split-режим → стек (код сверху, рендер снизу) |
| Средний (600–1000pt) | Сетка хаба → 3 колонки; split 50/50 |
| Большой (>1000pt) | Сетка хаба → 4–5 колонок; readingWidth остаётся 720 (не растягивается) |

Колонка чтения **всегда** центрирована и ограничена `readingWidth` — текст не растягивается на весь широкий экран (читабельность).

## 10. Микровзаимодействия (полировка)

- **Hover на карточке хаба** → лёгкое поднятие + тень.
- **Клик по карточке** → масштаб 0.98 на момент нажатия (`.scaleEffect`).
- **Переключение режимов** → opacity fade 0.18s.
- **Сохранение** → мигание кнопки / subtitle «Сохранено ✓» на 1.5с.
- **Пустой список недавних** → анимированная утка (лёгкое покачивание `rotationEffect`).
- **Баннер внешнего изменения** → slide-down анимация + пульсация таймера.
